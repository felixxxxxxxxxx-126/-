# 你的桌面小狗

根据你的照片制作的 macOS 桌面宠物原型：白色长毛、浅棕立耳、黑色鼻头。形象由 AI 参考照片生成，不是照片原样抠图。

## 在 Mac 上启动

已经安装 Node.js 的话，下载并解压整个项目，双击文件夹里的 **启动小狗.command** 即可。首次启动会自动安装依赖，请保持联网并等待。详细说明见「先看这里.txt」。

也可以使用终端：

安装 Node.js 22 或 24，然后在终端进入此项目文件夹：

```sh
npm ci
npm start
```

点击小狗可以摸摸，鼠标划过头部也会触发抚摸和摇尾，按住拖动可移动窗口。点击“跟随”后，把鼠标移远，她会迈腿朝鼠标走来；靠近后会停下并摇尾。再次点击“停下”关闭跟随。鼠标进入小狗窗口时会暂停移动，方便点击按钮；休息期间也会暂停跟随。底部还提供喂食、玩耍、休息和退出；macOS 菜单中的“召回小狗”可以把窗口带回主屏。支持键盘 Tab 和回车操作。所有互动都在本地运行，不需要账号、摄像头、麦克风或 API 密钥；鼠标坐标仅在本地用于动作，不记录或上传。

## 打包

在 macOS 上执行：

```sh
npm run pack:mac
```

`dist/` 中会生成 Apple Silicon 和 Intel 两种 ZIP 包。当前未配置开发者签名和公证，仅适合本地开发；公开分发仍需 Apple 开发者证书和公证。

## 当前范围

已有透明置顶窗口、跨工作区显示、拖动、鼠标跟随、摸头、迈腿和摇尾。使用写实照片形象分层制作二维动作，尚不是三维模型或逐帧视频；休息仍为文字与呼吸效果，尚无趴下、语音或聊天。跟随限制在小狗当前所在显示器的可见工作区域内，跨屏请手动拖动。悬浮窗口的透明区域暂不支持鼠标穿透。系统启用减少动态效果时保留互动反馈并减少视觉动画。

```sh
npm test
```

自动测试覆盖互动状态、休息唤醒、拖动手势、摸头、跟随暂停、移动速度及显示器边界。macOS 窗口行为、签名和打包需要在真实 Mac 上验证。
